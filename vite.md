_13 Sep 2026_

## 1. Getting Started

```bash
bun create vite my-vite-app # React, TypeScript, Oxlint, install with Bun - no
cd my-vite-app
bun i
bun run build
```
**package.json**
```json
  "scripts": {
    "dev": "bunx --bun vite",
    "build": "tsc -b && bunx --bun vite build",
  },
```

> 📦 Размер основного JS-бандла: 223 kB
>
> Особенности: Oxlint
